Integrate Google Tag Manager script to your Odoo website

Description

Google Tag Manager

Google Tag Manager (GTM) is a free tool that helps marketers easily add and manage website tracking codes (called tags) without editing the site's code.

It lets you connect your website to Google Analytics, Google Ads, and other marketing services, making it faster and simpler to track data and run campaigns.

How to set up Google Tag Manager

Setting up Google Tag Manager (GTM) with your Odoo website is straightforward:

  1. Create your GTM account and container at tagmanager.google.com to get your unique container ID.

  2. Add this container ID to your Odoo website's settings (Odoo handles injecting the GTM script automatically).

  3. Finally, manage all your tracking tags directly from the GTM interface. For detailed tag setup, refer to the Google manual here.

Testing GTM Integration
Important Testing Notes

Because the GTM script is designed not to fire for internal Odoo users, keep these testing tips in mind:

  • You won't see the GTM script if you're logged into Odoo with internal user access rights.
  • To properly test the Google Tag Manager script, **log out of Odoo**, or use an **incognito/private Browse window**, or use a **different web browser**.
